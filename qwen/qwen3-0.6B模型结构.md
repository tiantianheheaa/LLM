# Qwen3-0.6B 模型结构完整解析

> ⚠️ **版本说明**：HF 仓库 `config.json` 标注为 **36 层 Transformer**，部分资料提及 28 层，以下以 HF 官方配置（36层）为准。

---

## 一、整体架构一览

```
输入 Tokens [batch, seq_len]
        │
        ▼
┌─────────────────────────┐
│   Embedding Layer        │  vocab_size=151936 → hidden=1536
│   (Token + Pos Embed)    │
└────────────┬────────────┘
             │ [batch, seq_len, 1536]
             ▼
     ┌───────────────┐
     │  RMSNorm (pre) │  ← 归一化，无 bias
     └───────┬───────┘
             │ [batch, seq_len, 1536]
             ▼
┌────────────────────────────────────────────────────┐
│            Transformer Block × 36 层                  │
│  ┌──────────────────────────────────────────────┐   │
│  │  Self-Attention (GQA: 12 Q / 4 KV heads)     │   │
│  │  + RoPE (θ=1,000,000)                        │   │
│  └──────────────────┬───────────────────────────┘   │
│                     │ [batch, seq_len, 1536]           │
│                     ▼                                  │
│  ┌──────────────────────────────────────────────┐   │
│  │  RMSNorm (post)                               │   │
│  └──────────────────┬───────────────────────────┘   │
│                     │ [batch, seq_len, 1536]           │
│                     ▼                                  │
│  ┌──────────────────────────────────────────────┐   │
│  │  SwiGLU FFN                                   │   │
│  │  gate: 1536→5376  up: 1536→5376              │   │
│  │  silu(gate) ⊙ up → down: 5376→1536           │   │
│  └──────────────────────────────────────────────┘   │
│                     │ [batch, seq_len, 1536]           │
└─────────────────────┴──────────────────────────────────┘
             │ [batch, seq_len, 1536]
             ▼
     ┌───────────────┐
     │  RMSNorm (final)│
     └───────┬───────┘
             │ [batch, seq_len, 1536]
             ▼
┌─────────────────────────┐
│   LM Head (不共享权重)    │  1536 → 151936
│   + Softmax → 概率分布    │
└─────────────────────────┘
             │
             ▼
     输出 Token ID [batch, seq_len]
```

## 二、核心参数总表

| 参数 | 值 | 含义 |
|------|-----|------|
| **vocab_size** | 151,936 | 词表大小（Byte-level BPE） |
| **hidden_size** | 1,536 | 隐藏层维度 |
| **num_layers** | **36** | Transformer 层数 |
| **num_attention_heads** | 12 | Q 头数 |
| **num_key_value_heads** | 4 | KV 头数 → **GQA 3:1** |
| **head_dim** | 128 | 每个头的维度（1536÷12=128） |
| **intermediate_size** | 5,376 | FFN 中间维度（SwiGLU） |
| **max_position_embeddings** | 32,768 | 上下文长度 |
| **rope_theta** | 1,000,000 | RoPE 旋转基数 |
| **tie_word_embeddings** | **false** | ❌ 输入输出嵌入**不共享** |
| **激活函数** | silu (SwiGLU) | 门控激活 |
| **归一化** | RMSNorm | 无 LayerNorm，无 bias |
| **qkv_bias** | true | QKV 使用 bias |
| **use_cache** | true | 推理启用 KV Cache |

## 三、逐层详细拆解（以第 i 层为例）

### 3.1 输入到第 1 层之前

| 组件 | 输入形状 | 输出形状 | 参数量 |
|------|----------|----------|--------|
| Token Embedding | `[B, L]` | `[B, L, 1536]` | 151936 × 1536 ≈ **233M** |
| RoPE 旋转位置编码 | — | 注入到 Attention | 0（无参数） |

> 📌 词表 151,936 是 Byte-level BPE，能处理任意 Unicode，包括 emoji。

---

### 3.2 单个 Transformer Block 内部（36 层完全相同）

这是模型的**核心计算单元**，每层做两件事：**注意力聚合信息** + **FFN 变换特征**。

```
输入 X: [B, L, 1536]
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  Step 1: RMSNorm (Pre-Attention)                     │
│  X₁ = RMSNorm(X)                                     │
│  输出: [B, L, 1536]                                  │
│  参数: 1536 (γ)                                      │
├─────────────────────────────────────────────────────┤
│  Step 2: Self-Attention (GQA + RoPE)                 │
│                                                       │
│  Q = X₁ @ W_Q    [B, L, 1536]  (12 heads × 128)     │
│  K = X₁ @ W_K    [B, L, 512]   (4 KV heads × 128)   │
│  V = X₁ @ W_V    [B, L, 512]   (4 KV heads × 128)   │
│                                                       │
│  Q += RoPE(Q)    ← 旋转位置编码                      │
│  K += RoPE(K)                                         │
│                                                       │
│  Attention = softmax(QKᵀ / √128) @ V                 │
│  输出: [B, L, 1536]                                  │
│                                                       │
│  参数:                                               │
│    W_Q: 1536×1536 = 2.36M                           │
│    W_K: 1536×512  = 0.79M                           │
│    W_V: 1536×512  = 0.79M                           │
│    W_O: 1536×1536 = 2.36M                           │
│    QKV bias: 1536+512+512 = 2.56K                   │
│    小计: ≈ **6.3M**                                  │
├─────────────────────────────────────────────────────┤
│  Step 3: 残差连接                                     │
│  X₂ = X + Attention_Output                           │
│  输出: [B, L, 1536]                                  │
├─────────────────────────────────────────────────────┤
│  Step 4: RMSNorm (Post-Attention)                     │
│  X₃ = RMSNorm(X₂)                                    │
│  输出: [B, L, 1536]                                  │
│  参数: 1536 (γ)                                      │
├─────────────────────────────────────────────────────┤
│  Step 5: SwiGLU FFN                                   │
│                                                       │
│  gate = X₃ @ W_gate   [B, L, 5376]                  │
│  up   = X₃ @ W_up     [B, L, 5376]                  │
│  act  = silu(gate) ⊙ up    [B, L, 5376]             │
│  down = act @ W_down  [B, L, 1536]                  │
│                                                       │
│  参数:                                               │
│    W_gate: 1536×5376 = 8.26M                         │
│    W_up:   1536×5376 = 8.26M                         │
│    W_down: 5376×1536 = 8.26M                         │
│    小计: ≈ **24.8M**                                 │
├─────────────────────────────────────────────────────┤
│  Step 6: 残差连接                                     │
│  输出 = X₂ + FFN_Output                               │
│  最终: [B, L, 1536] → 传入下一层                     │
└─────────────────────────────────────────────────────┘
```

#### 单层参数量汇总

| 子模块 | 参数量 | 占比 |
|--------|--------|------|
| Attention (Q+K+V+O + bias) | ~6.3M | 23% |
| SwiGLU FFN (gate+up+down) | ~24.8M | 74% |
| RMSNorm × 2 (γ) | ~3K | 0.1% |
| **单层合计** | **~31.1M** | — |
| **36 层合计** | **~1.12B** | — |

> 加上 Embedding (233M) + LM Head (233M) ≈ **1.58B**，但非嵌入参数约 **0.44B**（Embedding 不算入"模型参数"的常规统计）。

---

### 3.3 最终输出层

| 组件 | 输入 | 输出 | 参数量 |
|------|------|------|--------|
| Final RMSNorm | `[B, L, 1536]` | `[B, L, 1536]` | 1,536 |
| LM Head | `[B, L, 1536]` | `[B, L, 151936]` | 1536 × 151936 ≈ **233M** |
| Softmax | — | 概率分布 | 0 |

> ⚠️ **关键点**：`tie_word_embeddings=false`，所以 LM Head 是**独立的 233M 参数**，不与输入 Embedding 共享。这让输出表达力更强，但多了 233M 参数。

## 五、为什么这样设计？——关键设计决策

| 设计 | 选择 | 原因 |
|------|------|------|
| **GQA (12:4)** | 3:1 分组 | 推理时 KV Cache 减少 75%，速度提升显著 |
| **SwiGLU** | gate + up + down | 比 ReLU/GELU 效果更好，Qwen 系列标配 |
| **RMSNorm** | 无 bias | 比 LayerNorm 更快，训练更稳定 |
| **不共享 Embedding** | tie=false | 输出头独立，表达力更强（代价：+233M 参数） |
| **RoPE θ=1M** | 高频旋转 | 支持长上下文外推（32K → 131K） |
| **36 层** | 深度优先 | 0.6B 参数下，加深比加宽更有效 |
| **head_dim=128** | 小头设计 | 128 是注意力质量的甜蜜点，太大反而噪声多 |

> **Qwen3-0.6B = 36 层 Transformer × GQA(12:4) × SwiGLU × RMSNorm × RoPE，词表 152K，隐藏 1536 维，Embedding 不共享，专为低延迟推理优化的小钢炮。**
